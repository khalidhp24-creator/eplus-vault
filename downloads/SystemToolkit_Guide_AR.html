دليل شرح أوامر أداة إدارة وصيانة النظام (ePlus System Toolkit)

مرجع عربي شامل لجميع أوامر ملف SystemToolkit.exe (إصدار 32-bit و 64-bit)

تُعد أداة ePlus System Toolkit مركزاً متكاملاً لإدارة أنظمة ويندوز وصيانتها وإعدادها للعمل مع منظومة ePlus وقواعد بيانات SQL ومشاركة الطابعات عبر الشبكة. يُفضَّل تشغيل الأداة بصلاحيات المسؤول (تشغيل كمسؤول / Run as Administrator) لضمان تنفيذ جميع تعديلات النظام والسجل (Registry) وجدار الحماية بنجاح، كما تتيح الأداة تشغيل كل أمر على حدة أو تحديد عدة أوامر لتنفيذها دفعة واحدة.

قائمة الأوامر الـ 24 بالتفصيل

  • 1. عرض معلومات النظام والشبكة والمعرّفات — [0] System Info

    يعرض تقريراً تفصيلياً عن إصدار ويندوز ورقم البناء وتاريخ التثبيت ومدة التشغيل (Uptime)، بالإضافة إلى بطاقات الشبكة النشطة (عنوان IP وعنوان MAC والبوابة الافتراضية وخوادم DNS) ومعرّفات الاتصال عن بُعد لبرامج AnyDesk و TeamViewer مع إمكانية نسخها للحافظة فوراً.

  • 2. تفعيل أو تعطيل وضع السبات — [1] Enable / Disable Hibernation

    يفحص الحالة الحالية لوضع السبات (Hibernation) في الجهاز ويتيح تعطيله لإلغاء ملف hiberfil.sys وتوفير مساحة القرص (مع ضبط السكون عند التوصيل بالكهرباء على Never)، أو إعادة تفعيله عند الحاجة.

  • 3. إنشاء مستخدم مسؤول للدعم الفني — [2] Create Admin User (admin-eplus)

    يفتح نافذة مملوءة مسبقاً ببيانات حساب المسؤول المحلي (admin-eplus) لإنشاء الحساب تلقائياً وإضافته إلى مجموعة المسؤولين (Administrators) لتسهيل أعمال الصيانة والدعم الفني.

  • 4. إنشاء مجلدات النسخ الاحتياطي تلقائياً — [3] Create 'backup' Folders on Drives (D: - H:)

    يفحص جميع الأقراص المتاحة من D: حتى H: وينشئ مجلداً باسم backup على جذر كل قرص (مثل D:\backup\ و E:\backup\) في حال عدم وجوده لحفظ النسخ الاحتياطية لقاعدة البيانات.

  • 5. تفعيل جدار الحماية وفتح منافذ SQL — [4] Enable Firewall + Open Ports 1433-1434 (TCP/UDP)

    يفعّل جدار حماية ويندوز على جميع ملفات تعريف الشبكة ويضيف قواعد سماح للاتصالات الواردة عبر المنافذ 1433 و 1434 لبروتوكولي TCP و UDP لضمان اتصال الأجهزة الفرعية بخادم SQL Server دون حظر.

  • 6. إيقاف جدار حماية ويندوز — [5] Disable Windows Firewall

    يعطّل جدار حماية ويندوز بالكامل عبر جميع ملفات تعريف الشبكة (Domain و Private و Public) بشكل سريع لاختبار الاتصال أو حل مشاكل الحظر الداخلي.

  • 7. التحكم في خدمة تحديثات ويندوز — [6] Enable / Disable Windows Update Service

    يتيح إدارة خدمة تحديثات ويندوز (wuauserv) إما بإيقافها وتغيير نوع بدء التشغيل إلى معطّل (Disabled) لمنع إعادة التشغيل المفاجئ، أو إعادة تفعيلها وتشغيلها تلقائياً عند الرغبة.

  • 8. ضبط مؤقت وضع السكون — [7] Configure Sleep Timer (Never / 10m / 1h / 3h)

    يضبط مهلة دخول الجهاز في وضع السكون (Standby) أثناء التوصيل بالكهرباء أو على البطارية عبر أداة powercfg على أحد الخيارات: أبداً (Never)، 10 دقائق، ساعة واحدة، أو 3 ساعات.

  • 9. إنشاء نقطة استعادة نظام فورية — [8] Make System Restore Point Now

    يفعّل ميزة استعادة النظام (System Restore) على قرص النظام C: وينشئ نقطة استعادة فورية مؤرخة بالتاريخ والوقت للرجوع إليها قبل إجراء أي تعديلات حساسة.

  • 10. فحص وإصلاح ملفات النظام — [9] System Maintenance: SFC Scan (sfc /scannow)

    يشغّل أداة مدقق ملفات النظام (sfc /scannow) لفحص ملفات ويندوز الأساسية واكتشاف الملفات التالفة أو المفقودة واستبدالها تلقائياً بنسخ سليمة.

  • 11. ضبط الإعدادات الإقليمية لبرنامج ePlus — [10] Set Regional Settings to ePlus

    يهيئ إعدادات السجل الإقليمية للمستخدم الحالي (HKCU\Control Panel\International) لضبط تنسيق التاريخ إلى dd/MM/yyyy وتنسيق الوقت إلى hh:mm:ss tt مع صيغة صباحاً/مساءً وإعدادات en-US والأرقام بما يتوافق تماماً مع برنامج ePlus.

  • 12. تنظيف الملفات المؤقتة والكاش — [11] Clear Temp, Recent & Prefetch Folders

    ينظف مجلدات الملفات المؤقتة بأمان بما في ذلك C:\Windows\Temp ومجلد %TEMP% وعناصر Recent ومجلد C:\Windows\Prefetch لتحرير المساحة وتحسين استجابة الجهاز.

  • 13. فحص وإصلاح صورة النظام — [12] System Maintenance: DISM Scan (/RestoreHealth)

    ينفذ أمر الصيانة المتقدم DISM /Online /Cleanup-Image /RestoreHealth لإصلاح تلف صورة نظام ويندوز الأساسية ومخزن المكونات (Component Store).

  • 14. فحص وإصلاح أخطاء الأقراص الصلبة — [13] System Maintenance: CHKDSK

    يعرض الأقراص المكتشفة في الجهاز لاختيار أي قرص (C: أو D: وغيرها) وتنفيذ الفحص إما بالوضع السريع لإصلاح أخطاء نظام الملفات (/f) أو الفحص الشامل للقطاعات التالفة واستعادة البيانات القابلة للقراءة (/f /r).

  • 15. تعطيل التحكم في حساب المستخدم — [14] Disable UAC (User Account Control) Completely

    يعطّل تنبيهات التحكم في حساب المستخدم (UAC) بالكامل عبر ضبط القيمة EnableLUA = 0 في مسار HKLM\...\Policies\System (يتطلب إعادة تشغيل الجهاز لتفعيل التغيير).

  • 16. تفعيل المشاركة الشبكية بكلمة مرور — [15] Enable Printer & Network Sharing (Password ON)

    يفعّل قواعد مشاركة الملفات والطابعات واكتشاف الشبكة في جدار الحماية، ويفرض حماية المشاركة بكلمة مرور مع تعطيل حساب الضيف (Guest) لرفع مستوى الأمان.

  • 17. تفعيل المشاركة الشبكية بدون كلمة مرور — [16] Enable Printer & Network Sharing (Password OFF)

    يفعّل قواعد مشاركة الملفات والطابعات واكتشاف الشبكة مع السماح بالمشاركة المجهولة دون مطالبة بكلمة مرور وتفعيل حساب الضيف (Guest) لسهولة الربط في الشبكات الداخلية.

  • 18. إصلاح مشاركة الطابعات على السيرفر — [17] Fix Printer Sharing (Host / Server PC)

    يعالج أخطاء الاتصال بالطابعات المشتركة على الجهاز الرئيسي (Host/Server) عبر ضبط القيمة RpcAuthnLevelPrivacyEnabled = 0 في مسار Control\Print ثم إعادة تشغيل خدمة الطباعة (Print Spooler) تلقائياً.

  • 19. إصلاح مشاركة الطابعات على الأجهزة الفرعية — [18] Fix Printer Sharing (Client PC)

    يحُل مشاكل تثبيت تعريفات الطابعات المشتركة على الأجهزة الفرعية (Client PC) عبر ضبط القيمة RestrictDriverInstallationToAdministrators = 0 في سياسة PointAndPrint مع إعادة تشغيل خدمة Print Spooler تلقائياً.

  • 20. ضبط لغات النظام الإنجليزية والعربية — [19] Set System Language to EN (US) & AR (Egypt)

    يحدّث قائمة لغات المستخدم في ويندوز عبر PowerShell لتشمل اللغة الإنجليزية (الولايات المتحدة en-US) واللغة العربية (مصر ar-EG) بشكل قياسي.

  • 21. ضبط تخطيط لوحة المفاتيح — [20] Set Keyboard Layout to EN (US) & AR (Egypt)

    يعيد ضبط تخطيطات لوحة المفاتيح في السجل (HKCU\Keyboard Layout\Preload) لتثبيت الإنجليزية (00000409) والعربية المصرية (00000c01) وإزالة التخطيطات غير المرغوبة.

  • 22. إعادة تعيين إعدادات الشبكة بالكامل — [21] Reset Network Configuration (Winsock, TCP/IP, DNS)

    يعيد تهيئة مكدس الشبكة Winsock وبروتوكول TCP/IP ويفرّغ ذاكرة التخزين المؤقت لأسماء النطاقات (DNS Cache) لإصلاح أعطال الإنترنت والشبكة المحلية، مع عرض خيار إعادة تشغيل الجهاز خلال 15 ثانية.

  • 23. استثناء مجلدات النظام والتحميلات من الحماية — [22] Add Scan Exclusions (%USERPROFILE%\Downloads & Bconnect)

    يضيف مجلد التنزيلات للمستخدم الحالي ومجلد C:\Program Files (x86)\Bconnect وأي مجلد باسم Bconnect على جذور الأقراص المتاحة إلى قائمة استثناءات الفحص في Windows Security لمنع حذف أو تعطيل الملفات التشغيلية.

  • 24. أدوات الطباعة والطاقة والدعم عن بُعد والسجلات — [25–30] Spooler Reset, High Performance, Fast Startup & Remote Support

    مجموعة الأدوات المساندة الأخيرة في القائمة وتشمل: [25] إيقاف خدمة الطباعة ومسح مهام الطباعة العالقة في spool\PRINTERS ثم إعادة تشغيلها، و [26] تفعيل خطة الطاقة للأداء الأقصى (High Performance) وتعطيل ميزة فصل USB التلقائي (USB Selective Suspend)، و [27] تعطيل الإقلاع السريع (HiberbootEnabled = 0) لحل مشاكل المجلدات والطابعات المشتركة بعد التشغيل، و [28] التثبيت الصامت لبرامج الدعم عن بُعد (AnyDesk و RustDesk و UltraViewer و TightVNC)، و [29] إعادة تعيين معرّف AnyDesk لتوليد ID جديد، و [30] تصدير سجل العمليات الفاشلة إلى ملف .log مؤرخ لتسهيل المراجعة والدعم الفني.
